# Contributing

1. Never edit generated graph exports directly.
2. Never use chat history as repository authority.
3. Include `ruleset_id`, `book_id`, `source_id`, and `packet_id` where applicable.
4. Keep source assets and intermediate work within their book namespace.
5. Submit ontology changes through Architect decisions.
6. Submit graph mutations as reviewed GUPs and Integrator manifests.
7. Preserve legacy imports unchanged.
