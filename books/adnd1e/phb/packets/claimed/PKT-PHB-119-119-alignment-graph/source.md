## APPENDIX III: CHARACTER ALIGNMENT GRAPH {#p119}

The alignment graph plots the nine alignments on two axes: the ethical axis runs from lawful (left) through neutral to chaotic (right), and the moral axis runs from good (top) through neutral to evil (bottom), with absolute neutrality at the center. Each of the four corners names the extreme of its corner alignment.

|         | Lawful         | Neutral      | Chaotic         |
| ------- | -------------- | ------------ | --------------- |
| Good    | Lawful Good    | Neutral Good | Chaotic Good    |
| Neutral | Lawful Neutral | True Neutral | Chaotic Neutral |
| Evil    | Lawful Evil    | Neutral Evil | Chaotic Evil    |

| Corner Alignment | Description   |
| ---------------- | ------------- |
| Lawful Good      | Saintly       |
| Chaotic Good     | Beatific      |
| Lawful Evil      | Diabolic      |
| Chaotic Evil     | Demoniac      |
